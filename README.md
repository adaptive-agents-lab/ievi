# Implicit-Euler Value Iteration

Code and data for *Implicit-Euler Value Iteration: Long-Horizon Planning via Stable Integration of the Bellman Residual Flow*. [Paper](paper/manuscript/neurips_2026.pdf).

The package reproduces Figure 1, Figure B.1, Figures N.1–N.17 and Tables N.1–N.11. It includes the experiment configurations, tuning data and numerical results behind those figures, empirical tables and the numerical comparisons reported in the text.

See [REPRODUCE.md](REPRODUCE.md) for installation, figure generation and experiment commands. [Experiment methods](docs/experiments.md) describes the settings, metrics and statistical analysis; [data](docs/data.md) describes the included results and their coverage.
